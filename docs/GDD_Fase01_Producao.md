# 1. PROPÓSITO DA FASE

A primeira fase é a porta de entrada do jogador para o universo da LLM.

O jogador ainda não sabe o que é uma LLM.

Ele começa com uma pergunta simples:

> **Como uma máquina consegue representar alguma coisa?**

A fase acompanha a evolução:

```text
OBSERVAR
   ↓
CONTAR
   ↓
REPRESENTAR
   ↓
CRIAR REGRAS
   ↓
TRABALHAR COM INCERTEZA
   ↓
AUTOMATIZAR
   ↓
COMPUTAR
   ↓
REPRESENTAR COM MATRIZES
```

O objetivo narrativo não é ensinar toda a história da computação.

É fazer o jogador **sentir a evolução das ideias** que eventualmente tornam uma LLM possível.

# 3. REGRA DAS SIDE QUESTS

Side quests não são "aulas extras".

Elas devem nascer naturalmente do ambiente.

O jogador vê algo interessante.

NOVA comenta:

> "Tem alguma coisa estranha aqui."

O jogador investiga.

A experiência acontece.

Depois aparece:

> **CONCEITO DESCOBERTO**

E o Codex registra.

# 128. AS IMAGENS DE REFERÊNCIA

As imagens geradas anteriormente devem ser catalogadas como:

```text
REFERENCE ONLY
```

Elas não devem ser tratadas como:

- mapa definitivo
- escala definitiva
- layout definitivo
- modelo 3D
- gameplay final
- composição final da câmera

Elas servem para:

- direção artística
- arquitetura
- materiais
- atmosfera
- iluminação
- composição
- linguagem visual
